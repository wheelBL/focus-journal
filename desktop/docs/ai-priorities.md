# 优先级澄清与当前重点

## 使用流程

1. 从今日页进入“AI 帮我理清优先级”，或在 AI 助手中选择“理清优先级”。默认参考全部未完成任务，也可选择现有较小范围。
2. 说明困扰，例如事情很多、全都逾期。AI 从目标、重要性、硬约束、延期后果、剩余耗时和依赖出发，每轮集中询问少量影响判断的问题；不需要先填完一张评分表。
3. 连续回答、比较和修正。信息不足的地方保持未知；已经足够清楚时，给出有理由的下一步和暂缓原因。估计与实际投入分别保留，不把已投入时间直接当成重要性。
4. 调整任务时，AI 提出具体改写、日期、提醒、拆分、重点或审视建议，用户逐条确认。已有事项的回顾用事项审视；新增独立回顾工作需明确提出。
5. 应用后继续对话，助手读取最新任务及真实的应用结果。新增子项得到真实身份后，下一轮才可为它们建立依赖；依赖日期联动仍要核对完整影响范围。

## 边界

AI 不在后台自动修改、运行计时或生成虚假投入。不要把建议文字当作已应用结果。越出参考范围、数据已变化或关系已变化的提案应重新生成。当前重点与推荐顺序分别表达已确认的执行意图和对话中的判断；不新增必须维护的数值评分。

优先级模式先筛选未完成普通任务，再执行上下文大小限制；父路径、已经完成的前置只作为范围内背景。超出限制时明确显示部分覆盖，可缩小范围继续。对话最多保留最近 20 轮，过长模型回复可能截断；真实请求仅发送给用户已配置的服务。旧会话按日常整理模式恢复。

## 持续重点

当前重点保留到完成或移除，不要求每天重标。完成后的普通重新打开不恢复重点；撤销结束操作可恢复原状态。未来日期的重点不会提前出现，历史日期回顾不显示后来加入的任务。旧 focusDate 保留为日期意图，持续状态单独保存；升级只激活当天仍有效的未完成重点，较早历史不会自动全部复活。
