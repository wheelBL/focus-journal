# 快速记录

事项树、今日、新建窗口和 Windows 快速记录共用离线解析与保存规则。只写名称仍可保存，不要求学习语法。

| 输入 | 保存结果 |
| --- | --- |
| `写周报` 或 `. 写周报` | 可执行事项 |
| `- 接口约定 %参考` | 笔记／信息及自定义标签，无计时与完成要求 |
| `o 明天14:00-15:00 团队交流` | 独立事件时段，不计为实际投入 |
| `写周报 #工作/周报 %写作` | 放到已有归属下，附加自由标签 |
| `写周报 明天开始 周五17:00截止` | 计划日期与精确截止分开保存 |
| `提交材料 下周一前截止` | 下周一 00:00 前完成，不含周一 |
| `讨论 明天13:50提醒` | 独立提醒，不改截止或实际投入 |
| `读文章 估计50分钟` | 保存初始估计；未填时保持未知 |

前缀后需有空格；`ocean`、`.git`、`-flag` 不会被当成类型。字段之间用空格隔开。含空格的归属或标签用引号包住，例如 `#"工作/版本 2"`、`%"深入 工作"`。归属只匹配已有路径或唯一名称，不暗中创建项目。

明确支持今天、明天、后天、本周/下周的星期、`2026-10-23`、`10月23日`，以及 `17:00`、`下午3点半`。这是有限语法，不是任意自然语言理解。任务正文里的“明天下午写方案”保持正文；加开始、截止或提醒才指定属性。计划开始精确到日；提醒必须有时刻。无日期事件默认今天，预览显示日期。一个番茄估计按 25 分钟换算。

只有第一行识别前缀、标签、归属和时间。Shift+Enter 换行后的内容直接保存到正文，保留换行与普通符号，不再解释日期或 `#`、`%`。例如第一行 `- 接口备忘 %参考`，下一行 `正文保留 #标题 与 %原文`，会创建带参考标签的笔记，同时原样保存第二行。预览显示正文行数，点“编辑正文”可修改。

识别结果在保存前可见，点“修改预览”可修正类型、名称、归属、标签与时间。被误识别的片段可点选“保留为正文”；直接用引号包住也保持原文，例如 `检查 "明天截止"`。`\#`、`\%` 保留普通符号。重名、无效日期或归属不可用时不保存，原文保留。错误按字段修正：改名称不会清除截止错误，改截止后仍要通过计划与截止的关系校验。保存后才创建事项和标签，失败不会留下半条数据。

Windows 默认 `Ctrl+Alt+Space` 打开小窗口，托盘也有入口；设置可换键或关闭。Enter 保存并收起，Shift+Enter 换行，Escape 收起保留输入原文。草稿是本机设备信息，不进同步。退出再打开按当时日期重新解释相对日期，需查看预览。输入法组词 Enter 不触发保存。

树内保持 Enter 连续新增、Ctrl+Enter 保存结束、Tab 缩进与 Shift+Tab 提升的规则。正文编辑有自己的输入快捷键，不触发树操作。

笔记不接受计划、截止、估计、计时或提醒。事件有发生时间和可选提醒，不要求完成，不参与投入总量。它们可转为事项，保留 ID、正文与标签；转换后已有执行记录时不能改回信息类型。
