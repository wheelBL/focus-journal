# 七个场景的操作规则

2026-10-19，用户授权的实现与验收依据。保留今日时间线、任意层级、多计时器和到时继续计时。

| 操作 | 影响 | 撤销或恢复 | 验收 |
|---|---|---|---|
| 标题收集；保存并开始 | 默认收件箱；树内按同级/子级位置创建，不猜标签和日期；总估计可空 | 可改名、移动或移入回收站 | 标题即可保存和开始，不填写估计也能计时 |
| 同时计时 / 切换计时 | 同时继续其他计时器；切换只结束其他运行投入，不完成事项 | 已保存的时间保留，重新开始由用户决定 | 提醒一次只做一件事；每段时间有唯一归属 |
| 跨项目移动整支 | 保留标识、字段、投入，重新计算路径和当前归属；保存移动历史 | Ctrl+Z 撤销结构，计时与后来投入不回退 | 自身/后代不可作为落点；父级暂停和截止约束说明可见 |
| 树 / 平铺、聚焦与筛选 | 同一组条件；树显示弱化祖先，平铺只列匹配项；编辑行保持到离开 | 路径返回、恢复已保存条件 | 新增不补造日期；自动排序只接受确定的父级移动 |
| 更新剩余估计 | 初始估计保持；已投入来自记录，当前预计总投入=已投入+剩余 | 调整历史保留，再次调整 | 做一半发现低估仍可看到初始值；未知历史不补造 |
| 事项暂停 / 恢复 | 父级暂停阻止整支执行并暂停运行计时；子项自己的暂停状态不变 | 恢复事项/撤销状态，不自动恢复计时 | 暂停计时不等于暂停事项；有原因可查看 |
| 完成 / 取消父项 | 展示未结束子项和计时影响；明确选择整支处理或逐个处理 | 状态可撤销，已保存投入不回滚，计时不自动重开 | 不自动完成父项；取消不计入完成数；状态与计时原子保存 |
| 删除整支 | 可恢复地移入回收站，结束运行投入；不物理删除记录 | 撤销或从回收站恢复 | 子项影响清楚，原字段/层级/投入仍在 |
| 一键 GitCode 同步 | 比较本机、远端和上次一致版本；下载前校验和备份 | 本机备份、远端提交历史；冲突明确选择版本 | 双方更新不静默覆盖、不强推；断网可重试；下载计时暂停 |
| 本周回顾 | 按完成时间看完成，按投入区间看推进；项目/事项/标签筛选 | 直接调整计划、剩余估计、拆分、暂停 | 取消投入仍保留；跨周区间拆分；累计与去重时长分别显示 |

## 七条操作动线

1. **快速收集并开始**：可发现的新增入口 / Ctrl+N → 只输入标题 → 保存或保存并开始 → 已有运行计时时，可保留并行或切换。初始估计可暂空。
2. **多层跨项目移动**：事项树定位 → 拖动整支 → 看到放入/前后落点 → 提交 → 路径、项目汇总、暂停原因和截止冲突更新 → 可撤销。
3. **本周视图**：筛选截止在下周一前、未结束 → 保存视图 → 新增明确归属但不猜日期 → 修改日期后说明移出视图 → 自动排序下只移动父级。
4. **低估后的调整**：结束本次并可靠保存 → 可跳过小结 → 调整剩余估计 → 同时看到初始、投入、剩余、当前预计总投入和调整历史。
5. **父子状态联动**：选父项 → 暂停/完成/取消/回收站 → 查看整支与计时影响 → 确认 → 恢复或撤销只恢复事项状态，不重新启动计时。
6. **双机与冲突**：两台分别配置 GitCode → 一台收工同步 → 另一台同步再工作 → 双方改动时对比摘要并明确选择版本 → 下载先备份，失败保留本机。
7. **周末回顾**：本周 → 完成 / 有投入未完成 / 取消 → 项目、事项或标签筛选 → 查看累计与去重时间 → 直接改计划、剩余估计、拆分或暂停。

日期型截止按所选日当地零点排除当天；精确截止按时刻比较，以当前电脑时区显示。周一为每周起点。没有投入记录只表示“未记录投入”。本轮不增加依赖算法、复杂重复模板、多窗口仪表板或字段级同步合并。
