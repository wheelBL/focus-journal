# 定期事项审视：操作、影响与验收

审视对象是事项本身及完整子树，与一段时间的投入复盘分开。默认不开启，不用提醒声或弹窗催促。

| 操作 | 影响 | 恢复方式 | 验收重点 |
|---|---|---|---|
| 详情 / 右键设置 | 保存下次日期、一次或 N 天/周/月周期；显示上次审视 | 重新设置或关闭 | 旧事项没有推测出来的历史；不同于计划开始、截止 |
| 到期打开 | 日期不晚于今天进入一条队列记录；父子相邻 | 浏览可中断，保留位置 | 不自动记已审视；暂停项仍出现 |
| 浏览完整子树 | 展开未结束后代；可查看已结束项、行内编辑和详情 | 回工作页恢复原筛选与浏览位置 | 不受工作标签、可执行或截止筛选限制 |
| 已审视 | 写独立历史；按实际审视日安排下次 | 撤销最近批次，原记录标记已撤销 | 一次结束安排；月末、闰年有统一规则；重复请求幂等 |
| 同时审视子项 | 只处理明确勾选的子项，各自按自己的周期 | 整批撤销，先校验没有后续修改 | 父项已审视不自动标记子项 |
| 稍后审视 | 只改下次日期 | 再次改日期 | 不记已审视，不改上次日期或周期 |
| 跳过 | 只改本轮浏览位置 | 点击队列项或重新查看跳过项 | 业务数据和历史不变 |
| 暂时放下，下次再看 | 明确选择暂停执行及审视日期；运行计时保存并暂停 | 恢复事项，计时仍需主动恢复 | 到期不会自动变成可执行 |
| 完成 / 取消 | 停止未来审视，保留历史 | 重新打开后自行开启；状态撤销恢复原安排 | 取消不算完成，投入仍在 |
| 移动 / 改名 / 回收站 | 保留标识、周期和历史；回收站暂不入队 | 恢复原事项即可继续安排 | 不复制、不重置日期、不丢历史 |
| 多机同步 | 周期、下次日期、审视日志随快照传递 | 本机备份或远端历史 | 凭据、浏览位置、跳过和设备偏好不随日志同步 |

主流程：回顾 → 事项审视 → 看完整子树与近期变化 → 需要时编辑 / 拆分 / 调整 → 明确已审视 / 推迟 / 跳过 / 暂时放下 → 下一项。

投入统计在右侧辅助信息内折叠。没有记录不表示没有推进；不把审视变成填写问卷或追求统计数量的任务。
