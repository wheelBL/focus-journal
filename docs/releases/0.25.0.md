# 专注记 0.25.0

沿用 Things 风格、浅深色主题和紧凑事项树，集中优化开始工作、连续整理、日历回看与投入复盘。保留已有项目、事项、投入、标签、视图、AI 和同步功能；日志结构仍为 17，无本次数据库迁移。

| 使用场景 | 改善 |
| --- | --- |
| 事项与投入累积很多，同时仍在计时 | 今日进展、时间线和投入复盘复用历史数据，每次刷新只叠加活动记录；累计与去重时长保持原有含义 |
| 回顾大量项目与事项 | 项目汇总共用索引，折叠内容按需渲染；事项先显示 60 条，再按需展开，合计始终包含全部结果 |
| 连续整理事项名称 | F2 编辑后 Enter 保存或 Escape 取消会返回当前行，方向键可继续选择；异步响应不会抢回已移走的焦点 |
| 用键盘浏览详情 | 左右方向键及 Home/End 切换内容、投入、复盘；只有活动页签进入 Tab 顺序，正文方向键保持正常 |
| 设置提醒、重复、审视、截止和标签 | 保存期间保护输入并阻止重复提交，错误保留草稿可重试；旧响应不关闭新弹窗或清空其他事项的新输入 |
| 编辑重复安排时其他数据刷新 | 正在填写的周期不再被无关刷新重置；输入法确认文字不会误提交截止或标签 |
| 晚间继续工作或隔天重新打开 | 选择今天后随日期变化继续显示当天；明确选择历史日期则固定；快速记录草稿保留 |
| 在日历与事项之间往返 | 日、周视图各自记住查看时段；改变刻度保持时间位置，“现在”可返回今天并定位当前时间 |
| 希望减少动效 | 设置分区导航也遵循减少动效偏好 |

旧版本仅保存绝对日期，无法判断当时是在看历史还是跟随今天，因此保留旧的历史选择；再次选择“今天”即可启用跟随。优化不改变计时、休息、提醒和数据保存规则。

测试使用隔离数据与合成记录。性能比较针对内存读模型，不代表 Windows 启动速度或实际个人数据上的界面帧率。后台持久化和每十秒保存的机制本轮保持原样。

升级前在旧版托盘中选择“退出专注记”，再运行完整新版文件夹中的“专注记.exe”，无需重新导入数据。

503 项自动化用例、47 项原生界面检查、21 项打包运行与 5 项重启检查通过。生产代码与受测包一致，压缩包已校验，测试进程与预览服务已退出。详细结果与界面证据见 [本地验证记录](../../desktop/qa-evidence/release-0.25.0/validation.md)。
