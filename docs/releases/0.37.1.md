# 0.37.1

修复屏边计时签圆角外出现实心白底（深色主题为深色底）的显示问题。

Electron 的 `getBackgroundColor()` 不返回透明度，旧外观管理器误把透明窗口当作普通窗口。现在由悬浮窗口显式声明透明背景，主题管理器在加载和主题切换时保留该策略，计时卡片本身仍按主题显示。

保留原有计时、暂停、休息、拖动和展开操作；日志数据结构仍为 22，无数据迁移。

验证包括真实 Electron 窗口的浅色、深色、跟随系统主题，以及展开/收起后的边角透明度像素检查。发布验证同步加入透明边角检查，防止普通背景色断言遗漏这个问题。

本机验证通过：12 项相关自动化测试、57 项隔离悬浮窗口检查、107 项 Windows 发布包检查、11 项重启检查。全部使用合成数据；测试结束关闭窗口及托盘，未操作个人日志。
