# 0.30.0 — macOS

增加 macOS Apple Silicon（arm64）和 Intel（x64）构建，复用现有事项、计时、回顾、AI、API 和同步逻辑，数据结构仍为 19。Windows 保持原有 Ctrl 操作与数据目录。

- macOS 使用原生菜单、红黄绿窗口按钮、菜单栏模板图标，点击 Dock 可恢复主窗口。
- 使用 Command 搜索、新增、保存与计时；树中提供无需 Insert 键的同级/子项创建和 Delete 操作。快捷键帮助随平台显示。
- 编辑菜单与快捷键根据当前操作位置区分文字编辑、事项全选与整理撤销。撤销直接处理最新已保存操作，不依赖界面快照的刷新速度。
- 全局快速记录默认 `⌘⇧Space`，支持自定义 Command / Option 组合。原有 Windows 自定义快捷键继续保留。
- 分别在两种原生 Mac runner 构建 ZIP / DMG，以隔离数据验证启动、真实键盘操作、SQLite 计时、交接、辅助窗口与重启保存。
- 生产与 QA 包的业务构建文件保持一致，生产包不包含测试入口、数据库或本机凭据。工作流核对架构、签名和归档，并提供 SHA-256。

当前采用 ad-hoc 签名，未接入 Apple Developer 证书或 Apple 公证；下载后可能需要系统确认打开。构建与验证结果见仓库 macOS 工作流。系统要求、架构选择、安装和数据迁移说明见 README。

## 验证结果（2026-11-01）

- [Mac 双架构工作流](https://github.com/wheelBL/focus-journal/actions/runs/41218363182) 全部通过：两种架构各 323 项领域测试、7 项平台测试、4 项 Sites 测试。
- macOS 15 Apple Silicon / Intel 各通过 17 项实际安装包运行检查、7 项重启检查；包含原生粘贴、文字与事项撤销、全选、SQLite 计时、交接、跨桌面辅助窗口、页面恢复和深色外观。
- 两种 Mac 包各有 37 个业务构建文件与实际运行的 QA 包逐字节一致；通过架构、ad-hoc 签名、ZIP / DMG 完整性检查，生产包不含 QA 入口或数据库。
- Windows 共用构建通过 24 项相关界面回归、25 项实际安装包运行检查和 7 项重启检查；生产包与 QA 包的 37 个业务构建文件一致。
- 全部原生检查均使用隔离示例数据，结束时剩余窗口为 0。未读取个人密钥，未调用在线 AI 服务，也未使用 Apple 签名凭据。
