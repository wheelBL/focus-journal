# 专注记 0.24.0

本次沿用已确认的 Things 风格、32 px 紧凑事项树和浅深色主题，集中改善速度、输入连续性与 AI 辅助工作。

## 按使用场景优化

| 使用场景 | 本次改善 |
| --- | --- |
| 事项和历史积累很多，想迅速找内容 | 搜索共用一次索引，分批展示结果；显示数量，正常结果默认排除删除和归档分支，查旧内容可显式包含 |
| 在搜索中发现还没记录 | Ctrl+N 可直接新建；Ctrl+K 选中搜索词，Esc 返回原页面，输入法组合输入不会误触 |
| 写到一半想切换页面或搜索 | 今日和全局快速记录保留完整草稿，包括预览修正、正文、误识别词的处理及日期解释基准 |
| 正在保存时继续按键或取消 | 快速记录、树内新增、行内编辑、事项/计划/估计/复盘及视图保存统一保护输入；失败保留草稿，可重试 |
| 全局快速记录重新打开 | 保留正在修改的字段和选区，不抢回正文光标；快捷键提示与实际行为一致 |
| 查日历和阶段投入 | 日历缓存历史部分，每秒只更新活动计时；回顾复用按事项的投入和估计索引，减少重复扫描 |
| 最小化或放入托盘 | 主窗口暂停界面轮询，返回立即对齐数据；主进程计时、提醒与浮窗继续运行 |

## 应用内 AI 助手

在设置 → AI 助手填写兼容 OpenAI Chat Completions 的服务地址、模型标识和 API Key。支持 DeepSeek 等兼容服务，也可连接本机 HTTP 模型服务。没有内置付费账户或密钥。

侧栏的“AI 助手”可参考今日或最近 7 天；事项详情的“AI 帮我梳理”以当前事项及子项为范围，带入累计投入与近 7 天的投入明细。发送前可展开查看事项清单；内容较多时会提示截断。支持整理、拆解、计划、标签、提醒、剩余估计和复盘建议。

模型回答先显示为文字及修改前后对比，每条建议需点击“确认应用”。每次确认通过既有业务命令保存，计时自然增长不会使建议失效；相关事项被修改后，旧建议会要求重新生成。取消请求不修改工作记录，重复确认不会重复创建。

API Key 使用 Windows 提供的加密保护，只保存在本机 `ai-config.json`，不进入日志数据库、备份或同步，也不回传界面。连接测试只发送一条短测试文本。模型服务的实际兼容性与额度仍需使用自己的密钥测试；本次验证使用本机模拟服务，没有调用付费模型。

实现协议参考 [DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)；设备密钥保护使用 [Electron safeStorage](https://www.electronjs.org/docs/latest/api/safe-storage) 的异步接口。

## 数据和安装

日志结构继续为 17，项目、事项、投入、标签、视图、回收站与时间线沿用原有存储。关闭旧版托盘中的“专注记”，再运行完整新版文件夹中的“专注记.exe”，无需导入数据。测试只使用隔离数据，结束后退出测试实例与托盘。

473 项自动化用例通过；Windows 原生界面 37 项、AI 端到端 17 项、打包启动 21 项和重启 5 项全部通过。QA 与生产包运行时代码一致，压缩包已校验。测试实例和预览服务均已退出。
