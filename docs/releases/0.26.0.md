# 专注记 0.26.0

保留 Things 风格、浅深色主题、紧凑事项树与今日时间线，继续改善长期计时、审视中断、设置保存和模块扩展。已有项目、事项、投入、标签、视图、AI 与同步功能保留；日志 schema 仍为 17，沿用原 dataPath，本次无需数据库迁移或重新导入。

| 使用场景 | 改善 |
| --- | --- |
| 事项和投入越来越多，仍需长时间计时 | 每十秒的计时保存只更新正在运行的投入，避免重复处理全部历史；单纯时间增长不再触发主界面重载历史 |
| 查看当前事项及父项投入，或按投入时长筛选 | 每十秒叠加活动计时增量，列表、父级汇总、详情和搜索保持一致；秒级计时仍持续更新，无需重算全部历史 |
| 数据保存耗时较长 | 修复保存期间可能漏算投入的问题；仍运行的计时器会累计保存耗时，已暂停或结束的记录保持原时长 |
| 写了一半审视说明，先处理别的工作 | 按事项保留说明、选中的子项和稍后日期；切换事项或离开页面后可接着写，推迟审视保留说明且不产生已审视记录 |
| 保存审视决定或批量整理时操作较快 | 保存中锁定本次输入并阻止重复提交；失败保留草稿可重试，较晚返回的结果不会清空后来选择的事项 |
| 调整专注、休息、提醒、快速记录与本机 API | 保存状态和错误就地显示，失败保留输入；快捷键被占用会明确显示未生效，API 状态读取失败可以重试 |
| 用键盘切换回顾内容或打开局部弹窗 | 回顾页签支持方向键、Home/End；局部弹窗打开时，Ctrl+N、Ctrl+K 不再穿透到背后页面 |
| 日常只使用今日、事项，偶尔查看其他模块 | 日历、回顾、设置、搜索和弹窗按需加载，辅助窗口仅加载所需模块；加载失败可以局部重试，主导航和计时保持可用 |

模块入口、加载恢复、页面职责和设置写入状态分开维护，便于继续添加内置能力。所有界面样式仍统一加载，避免延迟打开的页面覆盖夜间模式或列表密度。

合成数据、内存 SQLite 基准中，1,500 事项／6,001 投入的周期保存中位数由 38.24 ms 降至 0.61 ms；10,000 事项／40,001 投入由 363.16 ms 降至 7.07 ms。这是固定样本的服务与持久化路径测量，**不是应用启动、实际磁盘写入或个人数据上的界面速度实测**。慢写入、失败重试、多计时器事务回滚和重启恢复另有专项测试。

升级前从旧版托盘选择“退出专注记”，再运行完整新版文件夹中的“专注记.exe”。既有到时继续计时、休息、恢复与数据保存语义保留。

主工作区冷加载 JavaScript 从 551,338 字节降至 450,010 字节（减少 18.4%）；快速记录、提醒和悬浮计时窗口各自仅需约 219–235 KB。此指标包含当前界面需要的静态依赖，不等同于启动时间。

541 项自动回归通过（领域与服务 295、DOM 224、API 16、同步 2、Sites 4）。隔离 Electron 原生界面 71 项检查、Windows 打包运行 21 项和重启恢复 5 项检查通过。正式包与验收包 36 个运行文件完全一致，ZIP 中可执行文件和 ASAR 校验通过。所有本轮 QA 进程已退出，未关闭用户个人实例。详细范围、截图与边界见 [验证记录](../../desktop/qa-evidence/release-0.26.0/validation.md)。本轮未发布 GitHub。
