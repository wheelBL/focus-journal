# 0.32.0 — 循环提醒、收件箱整理与列表修正

事项可通过右键、详情或重复安排转为纯提醒。确认本次提醒后进入下一个日历周期，无需完成，不计入待办和完成统计。支持日、周、月、年；稍后提醒不改变原定时间。转换保留身份、子项和历史投入，转回事项可恢复原先的执行安排。

侧栏新增收件箱视图，直接查看未整理内容。默认每天本机时间 09:00 提醒，仅有内容时提醒；可在视图标题旁调整时间或关闭。提醒卡片可直接打开收件箱，或五分钟后再提醒。应用需运行，可留在托盘。原有收件箱节点仍可正常编辑和移动。

树形展开箭头只在当前筛选下有可见子项时出现。右键菜单在窗口内定位，过长时滚动，键盘 End/Home 可到达末项和首项。树形和平铺的阅读位置、展开状态与紧凑密度保持不变。

笔记、事件、分组和纯提醒不计入待办。普通父事项仍计入自身；纯分类应显式转为分组，不自动修改原数据。“本周需完成”仍根据截止时间筛选，计划开始和提醒时间不会被当成截止时间。

数据结构升级至 21，升级前自动备份。已有事项、投入、标记、业务活动和完成归属保留。新增 API 命令与界面使用相同规则；AI 不会绕过非执行类型的限制。

Windows 与 macOS 下载包由 GitHub Actions 构建。本地 Windows 使用独立合成数据验证，不读取个人服务密钥；测试完成后退出 QA 应用。

验证：357 项领域测试、20 项本机 API 测试、Git 同步和站点 Worker 测试通过。界面全量首轮 292 项中有 2 项计时测试被新收件箱提醒触发的业务修订影响；修正对应测试夹具后，相关界面与新功能 37 项复测全部通过。最终 Windows 包通过 43 项实际窗口操作和 7 项重启检查；菜单在 600px 高窗口可滚动并用键盘到达末项。正式包与测试包的 37 个业务代码文件一致，测试进程已全部退出。
