# 0.41.1 · 常用操作与执行首页

任务页将常用视图和保存的视图放在分组前，减少寻找视图时的滚动。分组列表可以整体收起，仍显示当前范围并可返回全部分组；展开状态和新增草稿按本机工作区保留。

- 右键菜单优先展示改名、当前重点、计时和完成，再排列创建与其他安排。保留原功能、键盘操作及可滚动菜单，不增加级联子菜单。
- 今日的“建议接下来”不再跟随随意浏览过的任务。优先推荐可执行的当前重点，并说明计划、截止或继续之前事项等依据；正在计时或暂停时不再并排推荐另一项。重点列表复用任务状态，已有投入不再误报待启动；卡片显示真实的上级路径。
- 收件箱显示当前整理位置，长表单中的操作栏保持可见。只有一条时显示“保存并结束整理”，避免没有下一条却仍提示继续；保护中文输入法与重复提交，保留切换后的草稿。

没有修改数据格式、计时记录、每日提醒配置或 AI 对话历史。操作记录仍限于操作、入口、结果和版本及既有元数据。

Windows 与 macOS 下载包由 GitHub Actions 构建。本机验证使用隔离的合成数据；macOS 原生运行由云端流程验证，本轮不等待云端产物。
