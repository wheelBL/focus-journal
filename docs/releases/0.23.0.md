# 专注记 0.23.0

将已确认的 Things 风格设计稿整合到正式 Windows 应用。保留任务树、任意层级、拖拽、行内编辑、快捷记录、标签、自定义视图、计时、日历、回顾、API 与同步能力。

- 统一浅色与深色界面：轻量导航、紧凑 32 px 事项行、右侧详情、今日执行与时间线。
- 侧栏底部快速切换跟随系统、浅色、深色；设置中的“外观与动效”可选择跟随系统、标准或减少动效。
- 主窗口、快速记录、到时提醒、屏边计时签及 Windows 标题栏共用外观；已打开或隐藏的辅助窗口随设置更新。
- 完成、展开折叠、缩进、拖拽和详情切换有短暂过渡。计时刷新不会反复播放动画；滚动、虚拟列表与大列表保持直接响应。
- 切换外观保留筛选、选中事项、输入草稿和计时。设备外观写入独立的 `appearance.json`，不修改日志数据，也不随日志同步。

日志结构继续为 17。本次外观升级无需数据迁移；原项目、事项、投入、复盘、标签、视图和回收站均沿用已有存储。应用名称与数据目录保持不变。此前的补入已工作时间、下一次提醒起点、放弃投入与恢复功能均保留。

解压完整 Windows 文件夹，双击“专注记.exe”。升级前先在旧版托盘选择“退出专注记”，再启动新版，无需导入数据。正常关闭主窗口仍保留托盘，完全退出使用托盘菜单或设置中的“保存并退出专注记”。

验证包括业务规则、React 交互、API、隔离 Git HTTP 同步、真实 Electron 交互和打包后的多窗口/重启检查。所有桌面验证使用独立数据；测试结束后正常退出并销毁托盘。详细证据见 `desktop/qa-evidence/release-0.23.0/`。
