# 0.31.1 — 树形与平铺切换保留位置

事项页切换树形和平铺时保留树的展开状态、选中事项及各自的阅读位置。再次点击已选中的显示方式不会重置列表。

树形模式下，在显示方式旁直接提供“全部展开”和“全部折叠”，不用进入“视图选项”。批量展开与折叠只影响当前视图中的分支，不改变筛选条件，也不会显示已隐藏的已完成事项。

本次不升级数据结构，不改变事项、分组或投入记录。Windows 与 macOS 下载包由 GitHub Actions 构建，详情见 README 的下载说明。

验证覆盖超过 400 行的虚拟列表实际显示位置、独立滚动位置、选中事项、折叠分支和筛选边界；32 项针对性回归及构建通过。Windows 隔离打包版通过 37 项操作和 7 项重启检查，正式版与 QA 包业务代码一致，测试退出后无 QA 窗口或进程。
