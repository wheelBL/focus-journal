# 0.34.0 — 可配置快捷键与直接退出

`Ctrl+F` 直接聚焦当前任务、笔记或提醒列表的搜索框；其他页面使用全局搜索。`Ctrl+K` 搜索全部内容，在全局搜索结果中按 `Ctrl+F` 继续搜索全部内容。macOS 使用 `⌘`。

设置新增“快捷键”：可配置搜索、新增、打开设置、帮助、页面切换、退出，以及事项树新增、改名、计时、完成和删除。点击快捷键框后按组合键，检查重复或保留键后统一保存；可以清除单项或恢复默认。帮助面板展示实际配置，并直接进入配置页面。原生全局快速记录保留独立配置。

文字编辑、输入法组合输入、弹窗和快捷键录入不会触发背后的树操作。树的方向键、Tab 层级操作、Enter 改名、选择和撤销保留固定行为。快捷键配置仅保存在本机，不修改或同步工作记录。

“退出专注记”移到侧栏底部，与设置并排；与托盘退出共用同一流程。已提交的操作自动保存，完全退出时保存并暂停计时。退出不会提交尚未保存的表单；关闭主窗口仍收起到托盘并继续计时。

退出流程先保存日志，成功后才清理后台服务和托盘。保存失败时保持服务可用并允许重试；清理某个服务失败不会跳过其余资源的清理。

数据结构保持 22，现有任务、笔记、提醒、分组、投入和活动记录保持不变。Windows 与 macOS 下载包继续由 GitHub Actions 构建；本地 Windows 验证不代表 macOS 原生验证。
