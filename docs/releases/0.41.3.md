# 专注记 0.41.3

Windows x64 会自动检查正式版本。点击系统通知、窗口顶部或托盘的“下载并安装”即可更新。下载包经过 SHA-256 校验，安装前保存并暂停计时，安装完成后重新打开工作区。

提供当前用户安装程序和便携 ZIP。从 0.41.2 及更早 Windows 版升级时，请先退出旧版，手动安装一次。

- 在「今日」按 Enter 保存记录后，可以看到实际保存去向。新任务可以直接开始计时或加入当前重点，连续记录时始终对刚保存的那一条操作。
- 「结束本次」后，默认按钮是「保存小结」。「结束并休息」仍会立即开始休息。
- 小结保存后，点击「查看本次记录」即可回看对应的时间段和文字。当天有事项完成时，「推进了什么」才会展开完成归属统计。
