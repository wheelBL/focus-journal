# 0.40.0 — 从服务选择 AI 模型

AI 设置可在填写服务地址和密钥后获取模型列表，再搜索、选择并保存；已有同源密钥可留空沿用，不要求先保存配置或填写模型。获取、刷新不会自动替换模型或保存草稿，当前自定义模型始终保留。

地址或密钥变化会取消旧查询并清除旧列表；失败、空结果或不完整列表有明确提示，并保留手动输入。模型清单来自服务公布的信息，不能证明对话或工具调用兼容；连接测试现在包含简短对话与一个不执行的工具定义，且不发送工作记录。

获取使用 [OpenAI 兼容的模型列表接口](https://developers.openai.com/api/reference/resources/models/methods/list)，不是固定的厂商型号表。读取在主进程完成；不跟随重定向或不可信分页链接，限制响应大小，同源复用现有密钥，密钥不返回界面或日志。

本版不升级日志数据结构，保留 24 及现有任务、投入和 AI 对话。Windows 云端重启验证改为等待原生窗口焦点与页面就绪，再发送实际快捷键，替代固定 80 毫秒延时。
