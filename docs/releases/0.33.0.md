# 0.33.0 — 任务、笔记、提醒独立入口与共享分组

左侧使用一套稳定主导航：今日、收件箱、任务、笔记、提醒、日历、回顾。任务、笔记、提醒共享明确显示的分组范围，各自保留筛选、选中内容与阅读位置。今日、收件箱、日历、回顾沿用各自范围。

任务入口只展示任务和分组。旧混合树的原始关系保持不变；笔记、事件或提醒下面的任务仍可访问，必要时显示原路径。分组继续汇总信息而不承担执行状态。今日时间线、任务计时与历史投入保留。

笔记提供正文编辑、搜索与标签筛选，可从选中文字或完整笔记生成新任务，也可关联已有任务。生成后保留原笔记、正文和身份，通过关联返回查看。未保存的草稿与文本选择保存在本机；切换模块或分组可继续编辑。已保存内容在其他入口更新时，编辑区同步更新；与未保存内容冲突时提示并保留草稿。

提醒集中列出独立提醒、任务附带提醒、事件提醒与交接跟进。可直接新建、编辑时间和重复、确认本次、稍后或停止提醒。任务的提醒重复使用独立规则，不生成额外任务，不改变完成统计，也不结束正在运行的计时。交接跟进仍按单次时间安排。

收件箱在右侧一次性编辑类型、名称、正文、归属分组及必要提醒时间，支持完整分组路径搜索、保存并下一条、跳过。默认每日 09:00、仅有未整理内容时提醒，可自行设置。不会自动重建已删除的收件箱。

搜索和原生提醒打开内容时，优先在右侧预览；返回保留原页面，明确选择“前往所在位置”才切换模块。创建、关联、整理与提醒安排均复用业务命令，本机 API 使用同样的校验、修订与幂等规则。

数据结构升级为 22，升级前自动备份。现有任务、原始父子关系、投入片段与业务活动保留；关联和独立提醒规则进入备份及同步。多设备同步前应将各设备升级至 0.33.0 或更新版本。

Windows 和 macOS 下载包由 GitHub Actions 构建。macOS 原生检查由对应平台的 Actions 执行，本地 Windows 检查不代替 macOS 验证。
