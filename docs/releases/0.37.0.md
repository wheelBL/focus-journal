# 0.37.0

AI 助手可以继续上一轮讨论，保留本机当前对话与已应用结果，关闭或重启后可继续。新对话明确清空当前会话；切换分析范围开始新会话，旧建议需重新生成后才能应用。AI 安排逾期任务审视时使用原事项的审视机制；新增审视默认单次，已有周期保持，不创建代替审视的收件箱任务。

统一事项编辑与状态变化的撤销/重做：Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z，Windows 默认同时支持 Ctrl+Y。快捷键可配置，输入框保留原生文字编辑；实际投入和计时不回退。受后续修改、关联记录或正在计时影响的撤销会拒绝并说明原因。撤销历史限本次运行。

解除两处组件循环依赖，笔记与提醒新建后通过命令回执定位新记录，避免并发创建选错内容。原数据结构保持 schema 22，无需迁移。架构检查见 [检查记录](../architecture-review-2026-11-03.md)。

验证使用合成业务数据与本机模拟 AI 服务；不代表已连接用户真实服务验证。Windows 在隔离包中验证，macOS 由 GitHub Actions 构建与验证。

本地验证通过：408 项业务测试、23 项 API 测试、4 项 Sites 构建测试，以及 AI、快捷键、详情和内容工作区的定向组件回归；Windows 实际安装目录运行 102 项操作检查与 11 项重启检查。正式包与测试包的 44 个应用代码文件一致，生产包不含 QA 入口或数据库。测试完成后无所属 QA 进程残留。
