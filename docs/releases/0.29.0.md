# 0.29.0 — 交接、完成归属与轻量记录

事项转交给他人后仍保留身份、历史投入和截止时间，不删除，也不计为本人完成。右键或右侧详情选择“交接给他人…”，填写接手人，可继续跟进并设置独立提醒。子项仅处理明确勾选的部分；涉及计时须确认结束并保存。支持重新接手。

- 完成归属区分本人、他人、共同完成和未注明；个人投入保留，成果分别统计。旧已完成事项不补造归属。
- 事项增加“已交接”“待他人跟进”视图，以及责任、接手人、交接日期和完成归属筛选。个人执行与今日重点排除已交接事项，仍可为沟通和验收记录投入。
- “回顾 → 活动记录”可切换业务活动、轻量操作和 AI 使用；事项详情可查看近期业务变化。
- 业务活动与成功修改一起保存，包含来源和修改前后变化；时钟刷新不记活动，导入和同步不重放旧活动。
- 轻量操作仅记录操作、入口、结果、应用版本，另有 ID/时间元数据；没有鼠标轨迹、输入值或推算点击步数。本机批量保存最近 5000 条，可暂停、清空和导出。
- AI 本机保存最近 200 次请求、发送清单、分析、建议、应用结果及服务实际返回用量，支持反馈和清理详细文本；生成成功与应用成功分别记录。密钥与授权头不进入记录。
- 日志备份与同步保留交接、归属和业务活动；操作摘要与 AI 详细文本仅在本机。结构 17 升级至 18 前自动备份，旧事项、投入、估计、复盘及笔记通过迁移验证。
- 修复休息提示下的大块空白及侧栏遮挡；交接视图只显示一个选中导航，清理记录失败保留确认窗口供重试。
