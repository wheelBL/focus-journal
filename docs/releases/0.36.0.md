# 0.36.0 — 事件直接保存，收件箱留给待澄清内容

快速记录中的事件默认直接进入日历和今日时间线，分组可以不选；普通任务、笔记的全局快速记录仍默认进入收件箱。保存预览与实际保存共用同一套去向规则，支持自动、稍后整理和不分组。明确选择的分组、树中位置及输入的归属路径继续生效。

保存去向与未完成的草稿一起保留，暂时关闭或保存失败后可以继续编辑。日历新建的内容已有明确用途，默认直接保存到最外层，不再自动进入收件箱。AI 新建建议和本机 API 同步采用事件默认去向，同时保留 AI 的范围检查与逐条确认。

已有收件箱事件不会自动搬动或根据历史日期推断已经整理。可以直接保存并移出收件箱，保留原事件的身份、日期、正文及子项；移出后不再计入每日整理数量。收件箱整理允许不选分组。

保留现有任务、分组、笔记、事件、提醒和投入记录，数据结构仍为 22，无历史数据迁移。Windows 与 macOS 下载包由 GitHub Actions 构建。
