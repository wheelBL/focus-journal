# 专注记 0.21.1

补齐先计时后的放弃与恢复流程，并修正补记、进展和休息操作中的退出问题。

- 结束后的补充弹窗和待补充列表均提供放弃投入；确认后移入已删除投入，不再计入时长。
- 今日和日历均可恢复。原记录编号、原始起止时间、暂停片段和进展保留，恢复后重新进入待补充列表。
- 稍后补充、稍后填写和关闭弹窗会保存已经输入的进展；手动补记的取消只丢弃尚未保存的草稿。
- 保存过程中保护当前表单；写入或恢复失败就地显示原因，不丢失草稿。
- 补记事项选择排除已删除、归档分支，已完成事项仍可补记。已有历史投入仍可保留原归属进行校正。
- 保存小结并休息改为一次原子写入；放弃投入不会打断已经开始的休息。
- 复用统一的投入回收站与异步表单处理，拆分手动补记和结束小结组件。本机 AI API 支持放弃时保留进展，以及保存小结后开始休息。

完整解压 `FocusJournal-0.21.1-Windows-x64.zip` 后运行 `专注记.exe`，无需 Node.js。启动前先从旧版托盘退出。数据结构保持 schema 16，既有事项、投入和今日时间线保留。

本次使用隔离数据完成业务、界面、API、同步、Worker 和真实 Electron 操作验证；测试结束退出全部 QA 实例。
