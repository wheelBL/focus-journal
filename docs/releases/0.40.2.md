# 0.40.2 — 失效截止转为有日期的回顾

AI 不再一律保留已经确认失效的个人计划截止。先澄清截止来源，涉及外部承诺或来源未知时询问是否可撤销、是否重新协商及延期后果；确认可撤销后，可提出清除旧截止并安排回顾的完整建议。已有有效回顾可以保留，避免无故延后。

清除已有截止必须附理由，并带有效审视保障；预览、确认、撤销同时覆盖截止与回顾。程序继续校验授权范围、最新数据和日期，无法核实的承诺事实仍由对话澄清。修正请求有次数限制，不会擅自应用建议。

今日页新增“需要重新判断”的直接入口，打开待审视队列。回顾日不算完成期限，到期后持续保留中性提示，不变成红色逾期；真实截止继续独立生效。修复已归档分支仍进入审视队列的问题。旧截止留在活动记录，事项、投入、当前重点及下游任务日期保留。

不改变数据格式，不需要迁移个人记录。Windows 使用隔离数据验证；跨平台下载包由 GitHub Actions 构建。

验证：473 项核心测试、45 项相关界面检查通过；Windows 打包验证 171 项、重启验证 12 项通过。QA 与正式包的 44 个应用代码文件一致，正式包不含 QA 入口或测试数据库；所有测试实例已退出。AI 请求使用本机合成服务验证，没有读取个人密钥或调用真实模型。
