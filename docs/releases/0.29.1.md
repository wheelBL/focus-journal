# 0.29.1 — 交接即关闭

交接后的事项采用独立的“已交接（关闭）”状态，关闭本人责任，退出默认未完成、个人执行和逾期队列。交接不计入完成或取消，原事项身份、截止时间、投入和活动历史保留。

- “已交接”“待他人跟进”视图仍可查找关闭的事项；跟进提醒独立有效。
- 重新接手后恢复未完成，不启动计时。只交接明确勾选的子项，未交接子项继续独立执行，即使父项已交接关闭。
- 交接项不显示开始计时，完成复选框不再暗示待办；需要时明确“记录他人完成…”，默认他人归属。
- 编辑或移除跟进提醒仅影响跟进安排，保留原事项提醒；重新接手后恢复原提醒。
- 交接不生成重复事项的新一期；明确记录实际完成后，再按原规则生成新的个人事项。
- 结构 18 升级至 19 前自动备份。旧版已交接且仍为 open 的事项自动关闭，保留历史，不补造完成或离线投入；旧的明确交接视图随状态语义迁移。
