# 0.41.0 · AI 助手侧栏

AI 助手由弹窗改为可调整宽度、可展开的侧栏。直接描述目标并连续追问，不再选择对话模式；参考范围独立可见，支持全部未完成任务和全部事项。

- 对话与待确认建议分开，跨轮保留仍有效的提案。支持编辑可修改字段、确认应用和有边界的撤销。
- 收起后继续生成，生成时可以写下一句；查看任务并返回后继续原来的编辑。草稿和阅读位置按对话保留。
- 完整本机对话归档不再受模型上下文轮数限制；新对话不清空旧记录，旧格式升级前备份。重启后的建议作为历史展示，不自动重放。
- 保留全部现有任务、分组、笔记、提醒、投入及日期规则。清除失效截止仍需有效回顾安排，外部承诺须先澄清。
- 输入法、文字编辑和助手快捷键不会触发后台任务操作；保持浅色、深色和紧凑布局。

Windows 与 macOS 下载包由 GitHub Actions 构建，本机 Windows 验证使用隔离合成数据。macOS 原生验证结果以 Actions 为准。
