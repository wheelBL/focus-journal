# 0.35.0 — 更准确的轻量操作记录

补齐内容类型、笔记关联和提醒重复规则的业务活动记录。后续转换为分组、调整关联或提醒重复时，可以看到实际变化；旧记录保持原样，不推测或补造历史。

轻量操作继续只保留操作、入口、结果和版本，以及原有的记录编号与时间。编辑操作区分改名称、改说明、设置截止等；入口在进入操作时确定，保存时焦点变化不会把它误归到其他位置。搜索、应用快捷键和快捷键设置的有效保存进入统计，普通文字输入不逐次记录。

明确取消和临时切换页面分别处理，保留草稿不算放弃。失败使用有限的原因类别，无法判断的保留未分类，不记录完整错误文本。操作采集不会阻止工作记录保存。

“回顾 → 活动记录 → 轻量操作”可以查看操作和入口汇总。对已核对的版本与入口，显示从明确起点完成操作所需的设计最少步骤；这不是实际点击次数或耗时。旧版本与无法匹配的路径显示未知。

采集维持本机存储、批量写入和数量上限，不采集鼠标轨迹、按键序列、搜索词或输入内容。任务、分组、笔记、提醒、投入和历史记录保留，数据结构继续为 22。Windows 与 macOS 包由 GitHub Actions 构建。
