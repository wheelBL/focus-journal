# 0.39.0 — 理清优先级与持续重点

今日页可直接进入“AI 帮我理清优先级”。助手结合范围内未完成任务、截止、估计、实际投入和依赖，通过连续对话询问重要性、实际紧迫性、延期后果与取舍，再提出下一步建议；不按逾期天数简单排序，不强制只选三项。

在对话中可以提议改写内容、调整计划与截止、设置提醒、拆分任务、安排事项审视；每条变更先预览、确认后应用。继续追问时使用最新记录和已应用结果。优先级模式及对话可恢复；切换模式或参考范围会开始新的对话边界。数据较多或历史受限时显示覆盖限制，模型不会收到全部无限历史。

“今日重点”改为“当前重点”，未完成的选择跨日保留，完成或移除后退出。保留旧意图日期，旧历史重点不会全部重新激活；数据结构升级到 24，升级前自动备份。默认推荐不会选择等待前置的任务，手动提前开始仍可用。

本版包含 0.38 的任务依赖、原间隔日期联动、固定截止冲突提示和整链撤销。Windows、macOS 下载包继续由 GitHub Actions 构建。
