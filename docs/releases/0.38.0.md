# 0.38.0 — 任务依赖与联动日期

任务详情支持设置前置任务，多选任务可预览并建立顺序依赖链。未完成前置时显示“等待前置”，开始计时会提醒但仍允许提前做。

截止时间默认按原间隔跟随前置调整，支持整条链和多个前置；固定截止不自动移动，冲突会提示。一次级联一起保存和撤销，已有任务、树结构、实际完成与历史投入保留。

AI 和本机 API 使用同一依赖规则。数据结构升级到 23，升级前自动备份；不会按旧任务顺序自动建立关系。详见[任务依赖说明](../../desktop/docs/dependencies.md)。Windows 与 macOS 下载包由 GitHub Actions 构建。
