# 0.27.0 — 精简界面，保留常用操作

本版逐块审查界面必要性，减少重复入口和常驻说明。保留 Things 风格、浅色/深色、32 px 事项行、全部既有能力与日志数据；不升级 schema 17。

- 事项：工具区收紧；显示已完成、展开折叠和保存/管理视图进入“视图选项”。已保存视图仍从侧栏打开，窄窗口保留下拉入口。默认两条关闭状态条件不再重复占一行；额外筛选、单条状态条件和 OR 组仍完整显示。
- 详情：面包屑只显示父级；AI、聚焦分支进入“更多操作”。计划、截止和标签直达；未设置的提醒、重复与定期审视进入“更多安排”，已有安排继续显示。
- 今日：去掉重复新增按钮与侧栏日期输入；快速记录、Ctrl+N、补记、重点、进展和时间线保留。相同精度的累计/覆盖时长合并展示，有差异或未指定时间时保留两项。
- 日历：保留图例，操作说明按需展开；有侧栏时不重复显示日周月切换，窄屏仍可切换。今日和日历仅在有已删除投入时显示恢复入口。
- 回顾：保留事项审视和投入复盘的不同职责；分类导航不重复，审视完整子树仍有完成显示、展开折叠、撤销和详情恢复操作。
- 设置：统一九类导航，每次显示一类；访问过的表单保持挂载，切换不丢未保存输入。窄窗口提供分类选择。
- 计时：选中事项详情已固定显示唯一计时器时，不再显示重复底部计时条；选中其他事项、关闭详情、切页或并行计时时仍保留。

验证：295 项领域测试、240 项 UI 测试、4 项 Sites 构建测试通过；隔离 Electron 检查明暗主题、700–1920 px 窗口、真实指针/键盘及收纳入口。Windows 包 21 项冒烟与 5 项重启持久化检查通过。首次打包冒烟遇到截图异常，退出后独立重试通过，保留首次诊断。所有 QA 窗口退出，未操作个人日志。

升级：从旧版托盘退出，再解压完整新包并运行“专注记.exe”。无需安装 Node.js。此版本尚未上传 GitHub Releases。
