# 专注记 0.21.0

首次 GitHub 发布，提供当前完整源码和 Windows 11 x64 便携版。

## 本版更新

- 新增屏边计时签：最小化或收至托盘时仍可查看事项与剩余时间，点击展开暂停、结束、休息和计时器切换。
- 可拖动并记住本机位置，隐藏不会停止计时；回到主界面自动收起，可从托盘找回。
- 明确显示超时、暂停、休息和欢迎继续；持续到时卡片优先，不自动开始下一轮，不重复计算投入。
- 保留事项树、今日执行首页与时间线、日历、重复、快速记录、复盘、本机 AI API 和 GitCode 同步。
- 为公开源码补齐独立测试初始化、可配置 Python 路径、构建文档与第三方组件许可证。

## 下载与更新

下载 `FocusJournal-0.21.0-Windows-x64.zip`，完整解压后运行 `专注记.exe`，无需 Node.js。请保留整个文件夹。

更新前先从旧版托盘中退出。既有事项、计时与投入记录保留；日志结构为 16，升级前自动备份。关闭主窗口会保留托盘运行，完全退出请使用托盘或设置菜单。

发布包未做 Windows 代码签名，`SHA256SUMS.txt` 用于核对下载完整性。生产包包含第三方许可证，不包含个人数据和测试配置。
