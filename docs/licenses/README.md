# License text sources

Most notices are copied directly from installed production dependencies by
`desktop/scripts/third-party-notices.mjs`.

The following npm packages omit a standalone license file; local copies are retained here:

- `@fluentui/react-icons` 2.0.344: [upstream Microsoft license](https://github.com/microsoft/fluentui-system-icons/blob/main/LICENSE).
- `clean-git-ref` 2.0.1: package metadata declares Apache-2.0, author Eli White. The notice contains that attribution and the Apache 2.0 terms distributed with `crc-32`, excluding its package-specific appendix.
- `diff3` 0.0.3: license headers from the distributed `diff3.js` and `onp.js`, preserving both sets of attribution.
- `minimisted` 2.0.1: package metadata and README declare MIT, author Yoshiya Hinosawa. The notice retains that attribution and the MIT text distributed with its dependency `minimist`.

Pako's zlib source notice is included alongside its package MIT license. These
files document third-party components; they do not license the Focus Journal project.
